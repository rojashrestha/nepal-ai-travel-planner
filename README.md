# nepal-ai-travel-planner
An end-to-end multi-agent AI travel planning system for Nepal, built with LangGraph, FastAPI, and Streamlit. Integrates flight search, hotel recommendations, and personalized itinerary generation.



## How to run? 

1. Create the virtual env
``` bash
conda create -n travel python=3.11 -y
```

2. Activate the environment 
 ``` bash
conda activate travel
```

3. Install the requirements 

```bash 
pip install -r requirements.txt
```
